# Nostalgie · Atelier 83

Landing page de la série Nostalgie, publiée sur https://aylmerlove.com

- `index.html` : la page (textes, style et formulaire)
- `images/` : les photos des pièces (`partage.jpg` = image d'aperçu sur Facebook et Messenger)
- `CNAME` : le nom de domaine pour GitHub Pages
- Hébergement : GitHub Pages (Settings > Pages > branche `main`, dossier racine)
- Inscriptions : Formspree, projet « Aylmer Love » (https://formspree.io/f/mvkzkder). Chaque inscription arrive aussi par courriel.
